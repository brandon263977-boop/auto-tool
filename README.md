# 自動排班系統

一個網頁就能用的排班工具：標好員工指定休，按一下「自動排班」，系統會排出每天早晚班人數都符合規則的班表，並可匯出 Excel。

## 線上使用

開啟 GitHub Pages 網址即可使用，不需安裝。資料存在自己電腦的瀏覽器裡，不會上傳。

## 班別

| 班別 | 時間 | 算早班 | 算晚班 |
|---|---|---|---|
| A 全天 | 10:30–23:00 | ✓ | ✓ |
| B 早班 | 10:30–18:00 | ✓ | |
| C 晚班1 | 18:00–23:00 | | ✓ |
| E 晚班3 | 17:00–22:00 | | ✓ |

## 人數規則

| 日子 | 早班 | 晚班 | 備註 |
|---|---|---|---|
| 平日（一～四） | 2 | 3 | A 最多 1 人 |
| 週五 | 2 | 4 | A 最多 1 人 |
| 假日（週六、國定假日） | 4 | 5 | |
| 週日 | 4 | 5 | 晚班其中 1 人排 E |

## 使用步驟

1. 「人員設定」輸入員工、可上的班別、可上的日子、每月目標休假天數。
2. 切到要排的月份，點格子標「指定休」（紅色）或固定班別。
3. 按「自動排班」，不滿意可再按一次。
4. 點上方日期可把某天改成平日／週五／假日／週日。
5. 按「匯出 Excel」。

國定假日依行政院人事行政總處公告，內建 2026 年 12 月至 2027 年底；之後的年份可點日期手動設定。
